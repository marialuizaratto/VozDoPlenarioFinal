# Projeto de API da Câmara dos Deputados

Esse projeto consiste em usar a API da Câmara dos Deputados, localizada no arquivo ENDPOINTS.md, processar os dados e entregar em uma nova API.

Essa API é feita em Python usando a biblioteca FASTAPI. 

A API terá as seguintes funções:

1: Listar discursos por deputado
2: Listar discursos por partido
3: Fazer uma nuvem de palavras a partir de todos os discursos de um deputado
4: Fazer uma nuvem de palavras a partir de todos os discursos de um partido
